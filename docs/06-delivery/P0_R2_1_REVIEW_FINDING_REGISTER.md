## Design corrections, implementation blockers, and owner decisions

**Design corrections in this remediation:** one host-service topology; Worker peer identity and lease binding; revocation/reservation/dispatch race ordering; exact payload digest binding; journal anchor and durability; non-IP egress inventory; independent termination proof; false-positive controls; and A–E execution stages.

**Unimplemented controls:** Gateway and Authorizer ticket enforcement; durable reservation ledger/journal/anchor; external network policy; real dual rootless daemons; effective resource/storage quotas; per-run terminator and startup fence; WSL-compatible service/socket model. Documentation does not verify these controls.

**Owner decisions still required:** accept/reject host root/systemd and signed update authority; accept/reject Runtime Engine daemon as TCB (or require stronger VM boundary); approve host-service topology and numeric UIDs/groups; approve journal anchor authority and retention; select independently enforced egress controls; approve a named disposable Linux VM/guest-root scope/cleanup authority; after VM evidence, separately approve named WSL distro/profile; decide whether to change ADR-0012 from Windows-locality to authenticated-principal access before researching Candidate C.
