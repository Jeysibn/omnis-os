# Starter Templates

These files are **documentation examples**, not active production configuration. They contain no genuine secrets, working provider credentials, or executable agent tasks. Implement runtime configs only after installed-version and policy verification.

- [Agent Profile](AGENT_PROFILE.example.yaml) - identity/personality/grants schema design.
- [Automation](AUTOMATION.example.yaml) - scheduled read-only task example.
- [MCP Connection](MCP_CONNECTION.example.yaml) - restricted read-only integration config.
- [Project Brief](PROJECT_BRIEF.template.md) - objectives, milestones and scope.
- [Knowledge Entry](KNOWLEDGE_ENTRY.template.md) - shared Second Brain review.
- [Issue](ISSUE.template.md) - implementation task and acceptance.
- [ADR](ADR.template.md) - architectural decision.
- [Environment](ENV.example) - redacted variable naming and local defaults.
